# STORY: MCP Server Configuration Viewer

**Epic**: [SCRUM-5](../epics/EPIC-SCRUM-5.md)  
**Complexity**: S  
**Persona**: Mark3 Engineer

## User Story
> As a **Mark3 Engineer**, I want to inspect the current MCP server configuration in a read-only viewer, so that I can confirm which MCP servers are wired without opening the raw JSON file.

## Context
`.claude/settings.json` is auto-generated by `setup.sh` and is not meant to be hand-edited. However, engineers need to quickly verify which servers are registered (element35, jira) and what commands/args are configured. A read-only viewer with syntax highlighting serves this need without risking accidental edits.

## Acceptance Criteria

- [ ] **AC-1**: Given the MCP Config page loads, when the page renders, then the content of `.claude/settings.json` is displayed in a read-only, syntax-highlighted JSON viewer.
- [ ] **AC-2**: Given the page is displayed, when the user attempts to edit the content (e.g. typing in the viewer), then no input is accepted — the field is explicitly non-editable.
- [ ] **AC-3**: Given the page loads, when the JSON is rendered, then a "Last modified" timestamp (from file mtime) is shown beneath the viewer.
- [ ] **AC-4**: Given `.claude/settings.json` does not exist, when the page loads, then a message "settings.json not found — run setup.sh to generate it" is shown instead of an error.
- [ ] **AC-5**: Given the page is displayed, when the user clicks "Refresh", then the viewer re-fetches and re-renders the current file contents from disk.

## Out of Scope
- Editing `.claude/settings.json` directly (always generated by `setup.sh`)
- Adding or removing MCP servers through the UI

## Dependencies
- [SCRUM-6](STORY-SCRUM-6.md) — app shell

## Notes / Open Questions
- Use a lightweight syntax highlighting component (e.g. `react-json-view` or a Prism-based approach). Full code editor not needed.
