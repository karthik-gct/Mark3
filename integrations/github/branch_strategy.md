# GitHub Branch Strategy

## Branch Naming Convention

All Mark3 feature branches follow:
```
feature/{jira-story-id}-{kebab-slug}
```

Examples:
- `feature/PROJ-42-user-auth-oauth`
- `feature/FLOW-17-dashboard-export-csv`
- `feature/MARK-5-search-filtering`

Rules:
- `{jira-story-id}` — exact Jira issue key (uppercase, as-is)
- `{kebab-slug}` — story title in lowercase kebab-case, max 40 chars, alphanumeric + hyphens only
- Total branch name max: 80 characters

## Branch Protection Rules (recommended)

Configure in GitHub repo settings:

```yaml
branches:
  main:
    required_status_checks:
      strict: true
      contexts:
        - "unit-tests"
        - "integration-tests"
        - "mark3-qa-gate"        # add this CI check
    required_pull_request_reviews:
      required_approving_review_count: 1
    dismiss_stale_reviews: true
    restrictions: null

  feature/*:
    allow_force_pushes: false    # prevents CodeAgent from accidentally force-pushing
    allow_deletions: false
```

## PR Template (auto-applied by CodeAgent)

CodeAgent uses this template when creating draft PRs:
```markdown
## Summary
{one paragraph from story title and key capability}

## Jira Story
Closes: [{story_key}]({jira_base_url}/browse/{story_key})

## Acceptance Criteria
- [ ] AC-1: {criterion}
- [ ] AC-2: {criterion}
- [ ] AC-3: {criterion}

## Test Plan
- **Unit tests**: {count} tests, {coverage}% new-code coverage
- **Test command**: `{command from ArchitectureDesign.md}`
- **QA status**: {PENDING | PASS — links to QA_REPORT}

## Notes
{any design decisions or trade-offs made during implementation}

---
🤖 Generated by Mark3 CodeAgent | Story: {story_key} | Branch: {branch}
```

## CI/CD Integration

Add a GitHub Actions step to verify Mark3 artifacts are present before merge:

```yaml
# .github/workflows/mark3-gate.yml
name: Mark3 Gate
on:
  pull_request:
    branches: [main]

jobs:
  check-artifacts:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Check Mark3 artifacts exist
        run: |
          STORY_KEY=$(echo "${{ github.head_ref }}" | grep -oE '[A-Z]+-[0-9]+')
          [ -f "artifacts/specs/SPECS-${STORY_KEY}.md" ] || (echo "Missing SPECS" && exit 1)
          [ -f "artifacts/designs/DESIGN-${STORY_KEY}.md" ] || (echo "Missing DESIGN" && exit 1)
          [ -f "artifacts/qa-reports/QA_REPORT-${STORY_KEY}.md" ] || (echo "Missing QA_REPORT" && exit 1)
          grep -q "READY" "artifacts/qa-reports/QA_REPORT-${STORY_KEY}.md" || (echo "QA not READY" && exit 1)
```

## Git Commands Used by CodeAgent

```bash
# Create feature branch
git checkout -b feature/{story-id}-{slug}

# Commit (never --no-verify)
git commit -m "feat({story-id}): {summary}

Closes: {jira-key}
Coverage: {n}% | Tests: {count}"

# Open draft PR
gh pr create --draft \
  --title "feat({story-id}): {summary}" \
  --body "$(cat <pr-body-template>)" \
  --base main
```
